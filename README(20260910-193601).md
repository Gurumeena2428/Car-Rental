# RentalGo — Full-Stack Car Rental Platform

This project upgrades the original HTML/CSS RentalGo website into a database-backed full-stack application.

## Stack

- Next.js 16 App Router
- React 19
- Prisma ORM 7
- SQLite for zero-setup local development
- `bcryptjs` password hashing
- `jose` signed JWT session stored in an HttpOnly cookie
- Next.js Route Handlers for the REST-style API

## Implemented features

### Customer
- Register, log in, log out, and restore a signed-in session
- Search cars stored in the database
- Search by car/brand/type, pickup and drop location, dates, transmission, fuel, seats, and type
- Availability checking against existing confirmed/pending bookings
- Create a persistent booking
- View bookings in `/dashboard`
- Cancel an active booking

### Admin
- Protected `/admin` dashboard
- View customer/car/booking/revenue statistics
- Add cars
- Edit cars
- Activate/archive cars
- Manage car locations
- View all bookings
- Change booking status to PENDING, CONFIRMED, CANCELLED, or COMPLETED

## Quick start

1. Copy `.env.example` to `.env`.
2. Replace `AUTH_SECRET` with a long random secret.
3. Run:

```bash
npm install
npm run db:setup
npm run db:test
npm run dev
```

Open `http://localhost:3000`.
